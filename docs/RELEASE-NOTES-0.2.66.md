# DiPlay v0.2.66 — Android 4.2 SETUP 兼容与车机日志负载优化

## 更新内容

### 1. Android 4.2 及以下 SETUP 循环失败与连接卡死修复
- **Closeable 类型擦除防护**：`DatagramSocket` 在 Android 4.4 (API 19) 以下未实现 `java.io.Closeable` 接口。此前在泛型绑定器中对 Closeable 上界进行转换时，在 API 17/18 平台运行时会触发 `ClassCastException`，导致 iPhone 端每次 SETUP 都异常失败并不断循环重试，车机界面卡死在连接中。
- **反射与安全关闭降级**：针对老旧系统统一使用反射及实例类型安全检查进行关闭释放，彻底修复低版本车机 SETUP 握手卡死问题。

### 2. 车机诊断日志收集独立控制开关
- **设置项独立控制**：在「设置 -> 诊断」中新增「日志输出」控制开关，重启应用后生效。
- **消除老车机 CPU/IO 负载**：在日常稳定使用场景下关闭日志输出后，彻底跳过会话格式化、脱敏与磁盘 I/O 写入，显著减少全志 T3、联发科等低性能车机的系统损耗，使画面与音频更加丝滑。排查问题时可随时一键重新启用。
- **多语言完整支持**：7 种语言文案原生适配。
