# DiPlay v0.2.68 — 有线传输独立线程、无线端口复用绑定与老旧车机兼容性优化

## 更新内容

### 1. 有线传输与 lwIP 吞吐优化
- **lwIP 数据发送改走独立线程**：将 lwIP 数据输出转移至专用发送线程异步处理，彻底消除 native 锁竞争阻塞，提升大流量数据传输吞吐与画面平滑度 (#187)。
- **lwIP 输入帧内存分配移入互斥锁**：将输入帧的 pbuf_alloc 移入互斥锁保护中，杜绝多线程释放时对 lwIP 内存堆的并发破坏与 SIGABRT 闪退。
- **StartSession 进度事件精确匹配**：细化有线握手会话进度监听，避免因无关看门狗消息触发握手失败或重连等待 (#187)。
- **VPN 授权被拒重新拉起入口**：当车机本地 VPN 授权被意外拒绝时，自动弹出引导重试对话框，无需退回桌面或插拔线缆即可重新授权 (#188)。
- **消除 iAP2 异常 suppressed 互指环路**：修复特定异常情况下 suppressed 异常自引环路导致日志输出时发生 `StackOverflowError` 崩溃。

### 2. 无线连接与网络稳定性
- **AirPlay 端口 TIME_WAIT 与双栈绑定优化**：针对重连时 RTSP/AirPlay 端口处于 TIME_WAIT 状态导致绑定异常的问题，引入套接字复用与 IPv4/IPv6 双栈智能绑定容错，显著提升无线二次连接成功率。
- **完善已有 Wi-Fi 模式参数解析**：增强网络参数格式兼容性，提升连接至车机现有热点时的配网成功率。
- **无蓝牙广播下 MAC 匹配**：当关闭蓝牙广播上报时，允许通过手动输入的 iPhone MAC 正常进入设备选择与配对流程 (#157)。
- **车机热点提示避免死循环**：移植车热点已关提示框逻辑，点击连接不再导致死循环重试 (#789)。

### 3. 老旧定制 Android 4.x / API 17 兼容性
- **低版本视频解码器名称版本保护**：针对 API < 21（Android 4.2 / 4.4）系统缺少 MediaCodec.getName() 的问题增加安全包装，彻底修复 Android 4.2 设备播放画面时抛出 NoSuchMethodError 闪退。
- **动态探测与降级 Cipher.updateAAD**：针对部分第三方定制车机（标称 Android 4.4 实际底层为 API 17）缺失 `Cipher.updateAAD` 导致无线控制通道握手崩溃的问题，引入反射探测并在不可用时平滑回退至 BouncyCastle ChaCha20-Poly1305 实现 (#189)。

### 4. 车机交互与音频优化
- **方控 Siri 键双击检测**：移植方控 `WheelSiriKey` 双击检测核心逻辑，提升多功能方向盘按键响应准确度 (#813)。
- **通话强制扬声器路由**：移植通话音频流被系统误路由到听筒时的强制扬声器切换逻辑，保证车载环境通话声音清晰可听 (#797)。

### 5. 发布安全与质量保障
- **发版前 Release APK 源码一致性自动校验**：引入 APK 内置 `version-control-info.textproto` 与当前源码的 0 diff 严格校验机制及 CI 门禁，杜绝发版脱节问题。
