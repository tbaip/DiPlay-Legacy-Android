# DiPlay v0.2.65 — 有线 CarPlay 拔插秒连与全屏侧边栏优化

## 更新内容

### 1. 全屏显示应用区域与边缘滑出手势 (可选配置)
- **设置项独立开关**：在「设置 -> 显示」中新增「全屏显示应用区域」开关（默认关闭），多语言原生支持。
- **平滑全屏变换**：开启后 CarPlay 右侧应用内容平滑横向填满整个车机屏幕，提升地图导航视野。
- **触控坐标像素级对齐**：全屏视口与触控归一化坐标精准对齐，无偏移。
- **智能边缘滑出手势**：在全屏状态下从屏幕侧边向内轻扫即可呼出应用侧边栏（Dock），5 秒无操作自动收回，或向外快速滑动即时收回。

### 2. 有线 CarPlay 拔插即时重连与稳定性优化
- **消除拔插重连延迟**：优化拔出检测与本地状态复位链路，重新拔插无需等待 1~2 分钟，实现即插即连。
- **TCP 丢包与高频重传消除**：增强 lwIP 用户态网络栈与链路帧过滤，降低 CPU 损耗，提升有线传输流畅度。
- **热路径日志精简**：移除音频/网络数据帧高频日志输出，释放老车机 CPU/IO 压力。

### 3. 车机交互与前后台体验修复
- **桌面失焦假死修复**：修复在 CarPlay 桌面停留一段时间后点击无响应、需要按车机返回键才能恢复的问题。
- **悬浮小白点智能展示**：小白点开关开启时，仅在退出 CarPlay 应用时展示，在 CarPlay 界面内部自动隐藏；小白点图标自动跟随当前应用图标。
